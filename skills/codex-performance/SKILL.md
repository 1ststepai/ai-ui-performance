# Codex Performance compatibility

Run the bundled scripts/Codex-Performance.ps1 with -Mode Check, Speed, or Restore. It delegates to the sibling ai-ui-performance skill with -App Codex and preserves earlier undo records. Both skill folders must be installed together. Read ../ai-ui-performance/SKILL.md for verification and limitations. This entry point does not optimize other apps.
